1. El tipo elemental string

 

Una cadena de caracteres o string es una secuencia de caracteres utilizada para representar texto.

Todo valor que sea de tipo string va entre comillas dobles. A continuación, se muestran varios ejemplos de cadenas de caracteres:

"Hello"
"Hello World!"
"A long time ago in a galaxy far, far away..."
"r"
"2189-FM"
"46"
"3.141592"
"$$%%&&...//@@??"

Es muy importante que los strings vayan entre comillas dobles, los caracteres con comillas simples y los enteros y reales sin comillas, ya que:

"r" es distinto de 'r': el primer valor es un string compuesto por un único carácter, mientras que el segundo es un carácter.
"46" es distinto de 46: el primer valor es un string compuesto por dos caracteres numéricos, mientras que el segundo es un entero. 
"3.141592" es distinto de 3.141592: el primer valor es un string compuesto por una serie de caracteres numéricos y un punto, mientras que el segundo es un real.

Por lo tanto, aplicaremos el mismo principio matemático que nos enseñaron de pequeños: «No podemos sumar peras y manzanas porque son frutas distintas». En este caso, no podemos realizar operaciones entre estos valores por tratarse de distintos tipos elementales de datos.

Las operaciones que se pueden realizar entre cadenas de caracteres son las de asignación, comparación y concatenación.

Como podemos observar, en lenguaje C, la constante que contiene el tamaño de la cadena de caracteres tiene por valor 10 + 1, en lugar de 10. ¿A qué se debe este +1?

En lenguaje C, los strings tienen asociado un carácter especial de finalización: '\0'. Este carácter especial es la marca que usa C para saber que la cadena de caracteres finaliza en ese punto y no en cualquier otro.

Cada vez que en C entramos un string desde teclado y pulsamos intro, automáticamente se añade el carácter '\0' al final de todo. Por este motivo, si tenemos que el tamaño máximo del nombre es de 10 caracteres y entramos un nombre de esa longitud, necesitamos reservar un espacio adicional (el +1 de antes) para el finalizador '\0'.

2.3. Comparación
Ejemplo 03

Debemos crear un programa que compare dos cadenas de tres caracteres como máximo para ver si son iguales o no, y si no lo son, que nos diga cuál va primero en orden alfabético. Para no complicarlo innecesariamente, supondremos que las dos cadenas de caracteres están escritas en mayúscula. El resultado debe mostrarse por el canal estándar de salida.

¿Cómo comparar dos cadenas de caracteres? Comparando el valor ASCII de los caracteres uno a uno.

Si asumimos que las cadenas están escritas en mayúsculas, los valores ASCII están ordenados alfabéticamente.

La comparación de los valores ASCII de strings funciona de la siguiente manera:

Si el primer valor ASCII de str1 > el primer valor ASCII de str2, significa que str1 > str2, y, por tanto, str2 va antes que str1 alfabéticamente.
Por el contrario, si el primer carácter de str1 < el primer carácter de str2, significa que str1 < str2, y str1 va antes que str2 alfabéticamente.
Si el primer carácter de str1 = que el primero de str2, comparamos el segundo de str1 con el segundo de str2 y así sucesivamente. Si llegamos al final y en todas las comparaciones el resultado ha sido igual, significa que ambos strings son iguales.

El planteamiento del ejercicio en pseudocódigo y en lenguaje C es el siguiente:

Pseudocódigo
	
C

algorithm compareStrings

    var
        str1: string;
        str2: string;
    end var

    writeString("Write the first string: ");
    str1 := readString();
    writeString("Write the second string: ");
    str2 := readString();

    if str1 = str2 then
        writeString(str1);
        writeString(" = ");
        writeString(str2);
    else
        if str1 > str2 then
            writeString(str1);
            writeString(" is alphabetically after ");
            writeString(str2);

            writeString(" is alphabetically before ");
            writeString(str2);

    end if

end algorithm

Un valor positivo, si str1 > str2. 

En función del resultado de la comparación, se muestra por el canal estándar de salida la relación existente entre str1 y str2.

 

2.4. Concatenación
Ejemplo 04

Necesitamos crear un programa que, dados un string con los caracteres numéricos de un DNI y otro string con la letra de este, los concatene en una nueva variable de tipo string. La entrada de valores debe realizarse desde el canal estándar de entrada, mientras que el resultado debe mostrarse por el canal estándar de salida.

Una posible manera de solucionar el ejercicio en pseudocódigo y en lenguaje C es la siguiente:

Pseudocódigo
	
C

algorithm concatenateStrings

    var
        numbers: string;
        letter: string;
        dni: string;
    end var

    writeString("Enter the numbers: ");
    numbers := readString();
    writeString("Enter the letter: ");
    letter := readString();

    dni := numbers + letter;

    writeString("The DNI is : ");
    writeString(dni);

end algorithm

	
#include <stdio.h>
#include <string.h>

#define MAX_NUMBERS 8+1
#define MAX_LETTER 1+1
#define MAX_DNI 9+1

int main() {

    char numbers[MAX_NUMBERS];
    char letter[MAX_LETTER];
    char dni[MAX_DNI];

    printf("Enter the numbers: ");
    scanf("%s", numbers);
    printf("Enter the letter: ");
    scanf("%s", letter);
    
    strcpy(dni, numbers);
    strcat(dni, letter);
    
    printf("The DNI is %s ", dni);

    return 0;
}

En pseudocódigo, podemos concatenar varios strings con el operador +.

En lenguaje C, tenemos que realizar dos pasos para concatenar los strings:

Primero, se copia el valor de numbers a dni con strcpy().
A continuación, se concatena letter al final del valor que tiene la variable dni con strcat().

Se muestra por el canal estándar de salida el valor de la variable string dni, que contiene la concatenación de numbers y letter.

 

La concatenación solo se puede realizar entre cadenas de caracteres. No es posible concatenar un string con ningún otro tipo elemental de datos. 

 

Resumen

 

Una cadena de caracteres o string es una secuencia de caracteres que se utiliza para representar texto.
Una cadena de caracteres siempre se escribe entre comillas dobles (“ ”), un carácter entre comillas simples (‘ ’), y los números reales y enteros sin comillas.
Una cadena de caracteres siempre termina con ‘\0’.
Las operaciones que podemos realizar entre cadenas de caracteres son las siguientes:

asignación
comparación
concatenación
