1. Estructura iterativa for

La estructura iterativa for se utiliza cuando hay que repetir un bloque de instrucciones un número de veces que conocemos a priori.

Para utilizar un bucle for, se tienen que especificar tres valores relacionados con el contador que controla las veces que se repite el bucle:

El valor inicial del contador.
La condición de salida.
El valor con el que se incrementa o decrementa el contador en cada iteración del bucle. Este valor se llama actualización del contador.

Todos estos parámetros se introducen en una única línea, lo que hace que la estructura sea muy eficiente y clara a la hora de escribirla.

 

Ejemplo 01. Cálculo del factorial de n

Calculamos el factorial de un número entero n utilizando la estructura for. 

Pseudocódigo
	
C

algorithm factorial2

    var 
        n : integer;
        i : integer;
        fact : integer;
    end var

    writeString("Introduce n");
    n := readInteger();
    fact := 1;

    if n ≥ 0 then
        for i := 1 to n do
             fact := fact * i;
        end for
        writeInteger(fact);
    else
        writeString("The number must be positive");
    end if

end algorithm

	
#include <stdio.h>

int main() {
    int n, i, fact;

    printf("Introduce n");
    scanf("%d", &n);
    fact = 1;

    if (n>=0) {
        for (i = 1; i <= n; i++) {
            fact = fact*i;
        }
        printf("%d", fact);
    } else {
        printf("The number must be positive");
    }

    return 0;
}

Fijaos en que, en el caso de la estructura iterativa for, hay menos líneas de código dentro del bucle que en el ejemplo de estructura iterativa while, de 14. Estructura iterativa while. En este caso, con solo una línea (fact := fact * i) tenemos el bucle listo. Esto es así porque el valor inicial (1), el valor final (n) y el incremento entre iteraciones se indica claramente en la definición de la estructura.

En C, la sintaxis de la composición iterativa for tiene tres partes dentro del paréntesis, separadas por «;»: inicialización, condición y actualización.

Observad también que no hay que inicializar la variable i antes de la estructura iterativa, porque se hace en la propia estructura. Por lo tanto, con la estructura for nos hemos ahorrado otra línea de código en comparación con la resolución del mismo problema con la estructura while.

Ejemplo 02. Cuenta el número de días

En el siguiente programa se registran las temperaturas medias diarias durante una semana y se cuenta el número de días en los que la temperatura fue igual o inferior a cero grados Celsius.

C

algorithm howManyDaysFreeze

        NUM_DAYS: integer = 7;

    var

        if dailyTemp[i] ≤ 0.0 then

2. Modificadores de la composición for

En los ejemplos anteriores, en cada iteración, el contador se incrementaba en una unidad. Pero puede haber situaciones en las que sea más conveniente aplicar otras opciones.

Imaginemos que queremos hacer una cuenta atrás desde un valor positivo determinado hasta 0. En este caso, en lugar de incrementar en una unidad el contador cada vez que finaliza una iteración, sería más conveniente sustraerla.

A continuación, veremos cómo se implementa este caso.

 

Ejemplo 03. Cuenta atrás
Pseudocódigo
	
C

algorithm countDown

    var 
        n: integer;
        k: integer;
    end var

    writeString("Introduce start number for count down:");
    n := readInteger();

    if n > 0 then
        for k := n to 0 step -1 do
            writeInteger(k);
        end for
    end if

end algorithm

	
#include <stdio.h>

int main() {
    int n, k;

    printf("Introduce start number:");
    scanf("%d", &n);

    if (n > 0){
        for (k = n; k > 0; k--) {
            printf("%d\n", k);
        }
    }

    return 0;
}

Fijaos en que, en pseudocódigo, hemos introducido el modificador step en la estructura for, que nos indica el incremento del contador en cada iteración. En este caso, disminuimos el valor del contador en una unidad en cada iteración. 

En el caso del programa C, en lugar de incrementar el valor de i usando i++, lo disminuimos, usando i--.

Ahora, imaginemos que queremos que, en cada iteración, el contador se aumente un valor diferente a 1.

 

Ejemplo 04. Suma de números pares

Queremos sumar los números pares comprendidos entre dos números, n y m, donde n <= m. 

Pseudocódigo
	
C

algorithm addEven

    var 
        n: integer;
        m: integer;
        k: integer;
        sum: integer;
    end var

    writeString("Introduce first number:");
    n := readInteger();
    writeString("Introduce second number:");
    m := readInteger();
    sum := 0;

    if n mod 2 ≠ 0 then
        n := n + 1; 
    end if

    for k := n to m step 2 do
        sum := sum + k;
    end for

    writeInteger(sum);
end algorithm

	
#include <stdio.h>

int main() {
    int n, m, k, sum;

    printf("Introduce first number:");
    scanf("%d", &n);
    printf("\nIntroduce second number:");
    scanf("%d", &m);
    sum = 0;

    // Check whether n is even.
    if (n % 2 > 0) { 
        n++; // If n is odd increase its value to become even

Ejemplo 05. Peso promedio

Queremos hacer un programa que nos ayude a calcular nuestro peso semanal promedio. Añadiremos por teclado las lecturas diarias de nuestro peso.

Pseudocódigo
	
C

algorithm averageWeight

    const
        NUM_DAYS: integer = 7;
        MIN_WEIGHT: real = 50.0;
        MAX_WEIGHT: real = 110.0;
    end const

    var 
        i: integer;
        weight: real;
        weights: vector[NUM_DAYS] of real;
        sumWeights: real;
    end var

    i := 1;
    sumWeights := 0.0;

    while i ≤ NUM_DAYS do
        writeString("Enter weight (kg.): ");
        weight := readReal();
        if MIN_WEIGHT ≤ weight and weight ≤ MAX_WEIGHT then
            weights[i] := weight ;
            i := i + 1;
       else                     
            writeString("Incorrect value.");
       end if
    end while
   
    for i := 1 to NUM_DAYS do
        sumWeights := sumWeights + weights[i];
    end for
   
    writeString("The weekly average weight is ");   
    writeReal(sumWeights / integerToReal(NUM_DAYS));

end algorithm

	
#include <stdio.h>

#define NUM_DAYS 7
#define MIN_WEIGHT 50.0
#define MAX_WEIGHT 110.0

int main() {
    int i; 
    float weight;
    float weights[NUM_DAYS];
    float sumWeights;

    i = 0;
    sumWeights = 0;

  while (i < NUM_DAYS) {
        printf("Enter weight (kg.)");
        scanf("%f", &weight);

        if (MIN_WEIGHT <= weight && weight <= MAX_WEIGHT) { 
            weights[i] = weight ;
            i = i + 1;
        } else {
            printf("Incorrect value.");
        }
    }

    for (i = 0; i < NUM_DAYS; i ++) {
        sumWeights = sumWeights + weights[i];
    }

    printf("The weekly average weight is ");
    printf("%f", sumWeights / NUM_DAYS);

    return 0;
}

Observad que en este ejemplo hemos utilizado dos estructuras iterativas for, y, dentro del cuerpo de una de estas, otra estructura iterativa while.

 

Resumen

 

La estructura iterativa for se utiliza cuando hay que repetir un bloque de instrucciones un número de veces que conocemos a priori.
Se implementa del siguiente modo:

    for i := startValue to endValue step increaseValue do
        {Code block}
    end for

	
for (i = startValue; i < endValue; i + increaseValue) {
    // Code block
}
El incremento entre iteraciones puede ser 1 o cualquier otro valor (incluso, negativo).
Las estructuras iterativas se pueden anidar.
Es habitual utilizar estructuras iterativas conjuntamente con vectores o matrices.
