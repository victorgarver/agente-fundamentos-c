1. Estructuras complejas

Ya hemos visto cómo se genera un nuevo tipo de datos estructurados tupla. Ahora veremos las opciones que aún no hemos valorado.

 

1.1. Tuplas que contienen tuplas

Al definir una tupla, no hay restricciones en cuanto a los tipos de datos que podemos usar en los campos. Por lo tanto, podemos hacer que uno de los campos de una tupla sea una tupla. 

Volvamos al ejemplo de los datos del carnet de identidad. 

 

Ejemplo 01

En este ejemplo, definimos nuevas tuplas que incluyen la fecha, el número y la letra del DNI. 

Pseudocódigo
	
C

type
    tDate = record
        day: integer;
        month: integer;
        year: integer;
    end record

    tDni = record
        idNumber: integer;
        idChar: char;
    end record

    tPeople = record
        surname: string;
        name:  string;
        birth: tDate;
        id: tDni;
    end record
end type

algorithm alg1207
    var
        you: tPeople;
    end var
end algorithm

	
#define MAX_LEN 25

typedef struct {
    int day;
    int month;
    int year;
} tDate;

typedef struct {
    int idNumber;
    char idChar;
} tDni;

typedef struct {
    char surname[MAX_LEN];
    char name[MAX_LEN];
    tDate birth;
    tDni id;
} tPeople;

int main() {
    /* Variable definition */
    tPeople you;
}

El uso de tuplas que contienen tuplas (estructura jerárquica de datos) requiere una notación jerárquica para acceder al valor de los campos. Pensemos en la variable you del tipo tPeople definido en el ejemplo 01:

you.name es una cadena de caracteres que contiene el valor del apellido.
you.birth es una tupla, es decir, una colección de tres valores int, que contiene la fecha de nacimiento. Para acceder a uno de estos campos, debemos usar el operador «.» otra vez. Para referirnos al día de nacimiento, usaremos you.birth.day.

Este proceso se puede repetir de manera recurrente si los campos internos de la tupla son, a su vez, tuplas.

 

1.2. Arrays de registros

De la misma manera que usamos los arrays cuando trabajamos con colecciones de tipos básicos, también podemos trabajar con colecciones de tuplas o arrays de tuplas (ya sean unidimensionales o multidimensionales). 

 

Ejemplo 02

Supongamos que tenemos que almacenar el DNI de todos los estudiantes de una clase.

Pseudocódigo
	
C

const
    MAX_STUDENTS: integer = 50;
end const

type
    tDate = record
        day: integer;
        month: integer;
        year: integer;
    end record

    tDni = record
        idNumber: integer;
        idChar: char;
    end record

    tPeople = record
        surname: string;
        name:  string;
        birth: tDate;
        id: tDni;
    end record
end type

algorithm alg1208
    var
        studentGroup: vector[MAX_STUDENTS] of tPeople;
    end var
end algorithm

	
#define MAX_LEN 25
#define MAX_STUDENTS 50

/* Types definition */
typedef struct {
    int day;
    int month;
    int year;
} tDate;

typedef struct {
    int idNumber;
    char idChar;
} tDni;

typedef struct {
    char surname[MAX_LEN];
    char name[MAX_LEN];
    tDate birth;
    tDni id;
} tPeople;

int main() {
    /* Variable definition */
    tPeople studentGroup[MAX_STUDENTS];
}

En la última línea del ejemplo 02, creamos la variable studentGroup, que es un vector de tuplas tPeople que tiene como máximo 50 elementos.

Para hacer referencia a un elemento i específico dentro del array, utilizaremos studentGroup[i]. En este caso nos estaremos refiriendo a la tupla de uno de los estudiantes, el que está en la posición i.

Si seguimos la misma notación que ya hemos explicado para acceder a los campos de esa tupla, tendremos que hacer nuevamente uso de la notación «.».

Veamos los siguientes ejemplos:

studentGroup[12] es la tupla que contiene toda la información del estudiante que está en la posición 12 del array.
studentGroup[12].name es el campo de texto que contiene el nombre del estudiante de la posición 12 del array.
studentGroup[12].birth.year es el campo que contiene la información del año de nacimiento del estudiante en la posición 12 del array.

También podemos pensar en arrays multidimensionales. Imaginemos que tenemos 6 grupos de 50 estudiantes, tendríamos que considerar el doble indexado del array.

 

Ejemplo 03

Generamos un programa que ilustra lo explicado en los párrafos anteriores.

Pseudocódigo
	
C

const
    MAX_STUDENTS: integer = 50;
    MAX_GROUPS: integer = 6;
end const

type
    tDate = record
        day: integer;
        month: integer;
        year: integer;
    end record

    tDni = record
        idNumber: integer;
        idChar: char;
    end record

    tPeople = record
        surname: string;
        name:  string;
        birth: tDate;
        id: tDni;
    end record
end type

algorithm alg1209
    var
        school: vector[MAX_GROUPS][MAX:_STUDENTS] of tPeople;
    end var
end algorithm

	
#define MAX_LEN 25
#define MAX_STUDENTS 50
#define MAX_GROUPS 6

/* Types definition */
typedef struct {
    int day;
    int month;
    int year;
} tDate;

typedef struct {
    int idNumber;
    char idChar;
} tDni;

typedef struct {
    char surname[MAX_LEN];
    char name[MAX_LEN];
    tDate birth;
    tDni id;
} tPeople;

int main() {
    /* Variable definition */
    tPeople school[MAX_GROUPS][MAX_STUDENTS];
}

En este caso:

school[2] se refiere a un array que representa a un conjunto completo de estudiantes, el que está en la segunda posición.
school[2][12] se refiere a una tupla, la correspondiente al estudiante 12 del grupo 2.
school[2][12]. name contiene el valor del nombre del estudiante 12 del grupo 2.
school[2][12].birth.year sería el año de la fecha de nacimiento del estudiante 12 del grupo 2.

 

1.3. Registros que contienen arrays

De manera similar al caso anterior, nos podemos encontrar con que uno de los campos internos de una tupla sea una colección de datos del mismo tipo.

Por ejemplo, imaginemos que queremos almacenar la información relativa a una asignatura. Necesitaremos guardar lo siguiente:

El nombre de la asignatura.
Las calificaciones de cinco actividades.
La calificación del examen.
La calificación de la evaluación final.

 

Ejemplo 04

En el siguiente ejemplo, creamos un registro para gestionar la situación anterior.

Pseudocódigo
	
C

const
    NUM_ACTIVITIES: integer = 5;
end const
type
    tSubject = record
        name: string;
        activitiesMarks: vector[NUM_ACTIVITIES] of char;
        test: real;
        finalMark: real;
    end record
end type

algorithm alg1210
    var
        computerScience: tSubject;
    end var
end algorithm

	
#define MAX_LEN 25
#define NUM_ACTIVITIES 5

/* Type definition */
typedef struct {
    char name[MAX_LEN];
    char activitiesMarks[NUM_ACTIVITIES];
    float test;
    float finalMark;
} tSubject;

int main() {
    /* Variable definition */
    tSubject computerScience;
}

Revisemos los contenidos de esta estructura:

computerScience es una variable de tipo tSubject, que es una tupla. Esta tupla guarda la información (nombre y notas) de un estudiante.
computerScience.activitiesMarks hace referencia a un array que contiene las calificaciones de las actividades de un estudiante, por ejemplo, [A,A,B,C,A].
computerScienc.activitiesMarks[3] contiene la información correspondiente a la calificación de la actividad 3.

 

Recordad

En pseudocódigo, la primera posición de un array tiene el índice 1: a[1].

En lenguaje C, la primera posición de un array tiene el índice 0: a[0].

 

 

Resumen

En esta unidad hemos visto lo siguiente:

Los tipos de datos estructurados tupla nos permiten crear tipos de datos nuevos que se adaptan a nuestras necesidades y que incluyen datos, o campos internos, que pueden ser de tipos diferentes.
Los diferentes campos de una tupla se guardan de manera consecutiva en la memoria.
Para acceder a los campos internos de una tupla, utilizaremos el operador «.».
Las tuplas pueden incluir tuplas o arrays, y también podemos crear arrays de tuplas. 
Podemos utilizar el operador «[]» o «.» para acceder a los diferentes elementos de una tupla compleja (que contiene otras tuplas o arrays).
