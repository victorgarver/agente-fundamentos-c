1. La información en un ordenador 

Los algoritmos y los programas siempre se pueden pensar como un procesado de información.

Por ejemplo, un programa que calcule el precio de un piso en función de su superficie puede tomar como datos de entrada la superficie del piso en metros cuadrados, datos con los que hará los cálculos necesarios (procesará la información) para calcular el precio del piso. Esos cálculos pueden ser más simples (podría multiplicar las dos cantidades) o más elaborados (podría tener en cuenta el código postal de donde se encuentra el piso para obtener un precio por metro cuadrado realista), pero, el concepto global es el mismo: tenemos unos datos de entrada y otros de salida. 

Esta estructura siempre se repite: se utiliza una serie de datos para manipularlos o procesarlos y obtener un resultado que nos interesa. 

En el caso de los cálculos, utilizaremos números, pero también podríamos hablar de texto (como el propio programa «Hello World!», en el que imprimimos por pantalla una frase). 

Así pues, dependiendo de lo que queramos que haga el programa, deberemos usar unos tipos de datos u otros. 

Pero ¿cuáles son los tipos de datos que podemos utilizar en nuestros programas?

 

1.1. Digitalización

¿Habéis oído hablar de la era digital? Se refiere, en general, a la época en la que las tecnologías de la información tienen una incidencia más relevante para la humanidad. Pero ¿por qué se llama digital? La digitalización es el proceso por el cual una cantidad es medida y guardada como un número. Digitalizar es transformar una cantidad física en un número. Por ejemplo, la temperatura es una magnitud del calor de las cosas. La podemos medir usando un termómetro y, por lo tanto, le podemos asignar un valor: la temperatura normalizada es de 25 ºC. Así pues, es relativamente fácil medir la temperatura y guardar su valor cada hora, cada día o la temperatura media de cada año.

Pero ¿qué quiere decir digitalizar una imagen? ¿O una canción? El proceso de digitalización de una imagen o de una canción es parecido al de la temperatura: utilizamos un dispositivo que sea capaz de «medir» una imagen (como una cámara, que transforma la cantidad de luz en una señal eléctrica) o un sonido (como un micrófono, que transforma las vibraciones generadas por el sonido en variaciones de una onda eléctrica) y transformar la señal que detecta en un número que codifica esa imagen o canción. Evidentemente, no es tan fácil como medir la temperatura, pero el proceso es análogo. 

En resumen, digitalizar es transformar una cantidad física del mundo real en números.

Hay muchísimos periféricos de un ordenador que permiten transformar en números cantidades físicas. Hemos hablado de la temperatura (termómetro), las imágenes (cámara) o los sonidos (micrófono). Pero hay muchos más:

El campo magnético: brújula.
El movimiento: giroscopio o acelerómetro.
La posición: GPS.
La distancia: telémetro láser.
Composición química: espectrómetro.

Casi cualquier cantidad física se puede medir, cuantificar y codificar en un número. Y toda esta información se puede guardar en la memoria de un ordenador y procesarla en un programa. 

 

1.2. Memoria de un ordenador: sistema binario

La digitalización es muy importante en las tecnologías de la información, y también lo es el desarrollo de las tecnologías que permiten guardar los valores de las medidas de la digitalización, esto es, la memoria del ordenador. 

Hay diferentes tipos de memorias de un ordenador, pero todas se basan en el mismo concepto: la capacidad de guardar una gran cantidad de 0 y 1. No entraremos en cómo es la tecnología que hace esto, pero la memoria RAM de un ordenador es capaz de guardar muchísimos de estos 0 y 1, y leerlos y escribirlos de manera muy rápida. Además, los discos duros son capaces de mantener esa información incluso cuando no les llega electricidad (al apagar el ordenador). 

¿Cómo se utilizan estos 0 y 1?

La unidad de almacenamiento que puede guardar un 0 o un 1 se llama bit.

Fijaos en que si tenemos 1 bit podemos contar hasta 2: 1 y 2 (o en realidad, 0 y 1).

Si tenemos 2 bits, podemos contar hasta 4:

2.1. Tipo booleano, boolean

El tipo booleano es el tipo de datos más simple que existe. Solo admite dos valores: true (cierto) o false (falso). Aunque no sea estrictamente correcto, a veces también se habla de 1 o 0, respectivamente. Esto se hace porque se asocia el valor 1 a true, y el valor 0 a false. Pero en realidad, y aunque en estos materiales a veces se hable de 0 y 1, los datos booleanos solo pueden ser true o false. 

El nombre de estos datos, booleanos, procede del álgebra de Boole, que está estrechamente ligada a la lógica. El álgebra de Boole define operaciones lógicas entre datos de tipo booleano. Se parece a la suma y la resta que conocemos para los números, pero «adaptada» a los datos de tipo booleano, que, como hemos dicho, solo pueden tomar los valores true (cierto o 1) o false (falso o 0).

Imaginemos que tenemos dos valores booleanos, que llamaremos a y b. Cada uno de estos valores puede concretarse en false o true. Las operaciones que se pueden realizar entre dos datos booleanos son las siguientes:

 

NOT a (operación NEGACIÓN de a)

La operación negación se aplica a un valor booleano, en este caso a. La operación NOT (negación) cambia el valor de a:

si a era true (o 1) pasa a ser false (o 0),
si a era false (o 0) pasa a ser true (o 1).

Podemos resumir la operación NOT en la siguiente tabla:

Dependiendo de los valores que tomen a y b, la operación a AND b da como resultado true o false. Si a y b son true, la operación a AND b (a y b) da como resultado true. De alguna manera, nos dice que la operación AND da como resultado true si a y b son true. En cambio, si una de las dos, o las dos, son false, la operación da false.

2.3. Tipo entero, integer

Los datos de tipo integer son parecidos a los números enteros: son los números 0, 1, 2, etc. Y también los negativos: -1, -2, -3, etc.

Los datos de tipo integer nos permiten realizar operaciones entre ellos. Pero, a diferencia de los datos de tipo booleano, los datos de tipo integer pueden operar entre sí mediante dos tipos de operaciones distintas:

Operaciones internas: son las operaciones entre números enteros que dan como resultado otro número entero.

2.4. Tipo entero en C: int

Los números integer en C se llaman int.

Los números enteros en matemáticas pueden tomar valores entre -∞ y +∞, pero esto no es posible en la realidad. Como hemos comentado anteriormente, el rango de números enteros que se puede representar puede ser muy grande y depende del número de bits que se utilicen para guardar un número entero. Como la memoria de un ordenador no es infinita, no podemos guardar números con valores que no quepan en esa memoria. 

Cuando se crea un compilador, se decide que los números int ocupen un espacio de memoria determinado. Dependiendo de los criterios que se adoptan al crear un compilador, se decide una cosa u otra. Normalmente, los números int ocupan entre 2 y 4 bytes.

Esta convención, utilizar 2 o 4 bytes para representar un número int, es una de las razones por las que utilizamos una máquina virtual en esta asignatura. Con la máquina virtual, nos aseguramos de que todos trabajamos «en el mismo ordenador» (como mínimo, en el mismo ordenador virtual) y tenemos el mismo compilador. De esta manera, no tendremos diferencias en cuanto al tamaño de los números, porque esa diferencia puede dar lugar a resultados distintos si no se tiene cuidado.

En el caso de CodeLite, en nuestra máquina virtual, los números int ocupan 4 bytes.

2.6. Tipo real en C: float

Como en el caso de los números enteros, existen infinitos números reales, pero nuestro ordenador no puede representarlos todos. Respecto a los números enteros, hemos comentado que existen infinitos números, tanto positivos como negativos. En el caso de los números reales, la cosa se complica aún más, ya que existen infinitos números, incluso entre dos números enteros. Es decir, hay infinitos números entre el 0 y el 1, entre el 0 y el -1, etc. 

Con un ordenador no podemos representar todos estos números, por lo que necesitamos representarlos de una manera que sea eficiente. Para eso, dividimos los números reales en dos partes:

Las cifras significativas (también llamadas mantisa o significando): aquellas que aportan información. Pensemos, por ejemplo, en el número pi, π. Es un número que tiene infinitos decimales. En cualquier caso, cuando lo utilizamos en cálculos reales, no empleamos infinitas cifras, sino que solemos usar unas cuatro o cinco cifras. Esto es porque las cantidades reales suelen tener un error asociado, y el número de cifras que realmente aportan información es relativamente pequeño. Por lo tanto, no tiene mucho sentido trabajar con el número 8.52780928120347809812734, y cometeremos un error bastante pequeño si trabajamos con 8.5278.
El orden de magnitud: si decidimos utilizar tres cifras significativas para describir un número, estas cifras pueden estar en las unidades (por ejemplo, 1.23), en los millares (1230) o en las centésimas (0.0123). Para trabajar de manera eficaz con estas cifras, podemos utilizar el formato exp o potencia de 10. Así, los números anteriores se pueden escribir como: 
1.23 = 1.23 x 1 = 1.23 x 100 = 1.23E0
1230 = 1.23 x 1000 = 1.23 x 103 = 1.23E3
0.0123 = 1.23 x 0.01 = 1.23 x 10-2 = 1.23E-2

Fijaos en que, como en los ejemplos anteriores, todos los números tienen el mismo número de cifras significativas (tres), pero con órdenes de magnitud diferentes. 

De este modo, los números muy grandes o muy pequeños se pueden representar de una manera más eficiente:

0.00000000000000000000000000000000009235845845 = 9.235845845E-35
2558846522018200000000000 = 2.5588465220182E24

La denominación float se refiere a la coma flotante, es decir, la coma denota la posición de la primera cifra significativa y puede estar en la magnitud unidades, centésimas o decenas de millar.

2.7. Tipo carácter, char

Otro tipo de dato es el tipo carácter, char, que sirve para representar:

Letras.
Dígitos (no números, sino dígitos, es decir, los caracteres que representan números).
Símbolos de puntuación.
Otros símbolos utilizados normalmente en informática.

Internamente, los caracteres están digitalizados y representados por números. A cada carácter le corresponde un número. Por ejemplo, podríamos inventar una representación de la siguiente manera:

Los dígitos del 0-9 podrían tener los códigos 0-9.
Las letras del abecedario (a, b, ..., z) podrían tener los códigos desde 10 a 26.

Pero aún nos faltarían las letras acentuadas (á, à, é, è, etc.), las diéresis (ï, ü, etc.), los signos de admiración, los interrogantes, etc. Es más complicado de lo que parece, y hay muchas maneras diferentes de hacerlo. 

El conjunto de correspondencias entre caracteres, números y símbolos se llama código.

Hay diferentes códigos, pero el más utilizado y el que se ha convertido en el estándar es el código ASCII (American Standard Code for Information Interchange), que utiliza un byte para representar cada carácter. Por lo tanto, en el código ASCII se pueden representar hasta 256 caracteres diferentes. Encontraréis la lista completa de códigos ASCII

No hay una manera de operar caracteres entre sí: no podemos calcular «a + b», ni «? * A». Esto no tiene sentido. Por lo tanto, no hay operadores internos entre datos de tipo carácter. 

En cambio, dado que los códigos (como el código ASCII) asignan un número a cada carácter, sí se puede definir un orden entre datos char y realizar operaciones de comparación entre ellos. Resumen

 

La información en un ordenador está digitalizada, lo que nos permite guardarla de manera efectiva.
La información en un ordenador se guarda en la memoria en forma de bits (0 y 1) que se juntan para formar bytes, que a su vez se unen para formar kilobytes, y así sucesivamente.
Un ordenador puede guardar diferentes tipos de datos. Hay muchos más, pero nosotros trabajaremos con:
Booleanos: este tipo de dato puede tener solamente dos valores, verdadero o falso. A veces, también se habla de 0 o 1.
Enteros: se corresponden con los números enteros en matemáticas. 
Reales (o de coma flotante): se corresponden con los números reales en matemáticas. 
Caracteres: se corresponden con letras, números y símbolos. Estos caracteres alfanuméricos se guardan como números en el ordenador, de manera que la correspondencia entre el número y el carácter viene dada por una tabla (en nuestro caso, ASCII).
Estos tipos de datos tienen su correspondencia en pseudocódigo y código C:

Hay una serie de operaciones definidas para cada uno de estos tipos de datos, que dan como resultado un nuevo valor del mismo tipo de dato (operaciones internas), y operaciones entre estos tipos de datos, que dan como resultado una variable booleana (operaciones externas).
