Introducción

Ya habéis conocido los tipos de datos elementales que se pueden utilizar en un programa. No obstante, si os dais cuenta, de momento solo sabemos hacer operaciones entre datos de un tipo, como si se tratase de una calculadora, o comparar diferentes valores entre sí. Pero esto no es lo que se busca, ya que lo que se necesita es definir maneras de tratar datos y, en caso de que estos cambien, de procesarlos de la misma forma sin tener que hacer nada más. 

Para esto existen las variables. En este apartado, aprenderéis lo que son las variables y cómo se definen primero en pseudocódigo y, después, en un programa en C. 

Volvamos al punto en el que se introducían las tablas de las funciones lógicas (NOT, AND y OR). Allí se hablaba de los valores a y b, que representaban dos valores booleanos que podían ser true o false. Fijaos, sin embargo, en que a y b no tienen un valor específico (los dos pueden ser true o false). Por lo tanto, a y b son variables.

Una variable es un nombre simbólico que hace referencia a una información concreta o a unos datos que se guardan en memoria. Cuando se trabaja con variables, en vez de hacerlo con un valor concreto, se escriben instrucciones que deberían funcionar para cualquier valor que tome esa variable. 

Ahora bien, una variable no debe considerarse únicamente una dirección de memoria, ya que tiene más información asociada. Al hablar de la memoria, hemos explicado brevemente que la información se guarda en un dispositivo utilizando un formato de 0 y 1. Pero guardar la información en un ordenador es algo más complicado que guardar 0 y 1. Es decir, ¿cómo se sabe que un 0 o un 1 pertenece a un número de 8 bits o a uno de 64 bits de tamaño?, ¿cómo se estructura la memoria para tener en cuenta estos aspectos?

Para dar respuesta a estas preguntas, se definen las variables en los programas. Cuando se ejecuta un programa, este pide un espacio de memoria al ordenador y lo gestiona guardando variables de diferentes tamaños en ese espacio. En todo momento, el programa ha de saber qué variable se guarda en cada parte de la memoria que el procesador le ha asignado. Es decir, a cada variable se le asigna un espacio de la memoria que tiene una dirección, de manera que el programa sabe en todo momento lo que tiene guardado y dónde. 

Una variable consta, como mínimo, de los siguientes atributos o características:

Nombre o identificador. Una variable puede tener cualquier nombre simbólico que se le quiera dar. Es recomendable que el nombre de una variable ayude a entender el tipo de información que guarda. Por ejemplo, si queremos guardar el saldo de una cuenta bancaria, podríamos llamar a la variable saldo; y si queremos guardar el coste de un bien, podríamos llamarla coste. Hay que tener en cuenta que, en ambos ejemplos, el valor que guardará la variable será un número real, pero el nombre ayudará a entender el significado del contenido de la variable dentro del programa.
Tipo de dato que la codifica. Como ya sabéis, puede ser boolean (bool), integer (int), real (float) o char (char).
Valor. El valor guardado de una variable es el valor concreto que tiene en un momento dado de la ejecución del programa. El valor irá cambiando según las operaciones que se hagan con ella, y siempre deberá ser un valor dentro del rango de valores válidos que puede tomar.
Dirección de memoria. La dirección de memoria es la posición en la que el valor de la variable está guardado. Internamente, durante la ejecución del programa, la dirección se utiliza para saber dónde guardar y encontrar el valor de la variable en cada momento. 
Visibilidad. Más adelante, veremos que un algoritmo está formado por diferentes partes. Las variables solo serán visibles en determinadas partes del algoritmo, en función de dónde estén definidas. 

Cuando se escribe un programa, es necesario describir cada una de las variables que se utilizan; es decir, si se va a emplear una variable que se llama a y que es de tipo booleano, hay que explicitar tanto el nombre como el tipo de dato que la variable va a guardar. Esto se realiza mediante la definición de la variable.

Es importante recordar que, al crear una variable, se le puede asignar un valor, que puede depender de los valores que haya en memoria en el momento de su creación. Por ejemplo, si al definir una variable, se le asigna un espacio de memoria en el que ya había valores de 0 y 1, puede que la variable se genere con un valor inicial que no conozcamos. Por eso, es importante que, siempre que se pueda, se inicialice la variable al crearla, es decir, que se le asigne un valor que tenga sentido.

En esta unidad, explicaremos cómo se definen e inicializan las variables.

 

1. Sintaxis de un programa

Cuando se escribe un programa, hay que hacerlo de manera que el compilador lo entienda, es decir, hay que seguir una sintaxis muy estricta. Si no se hace así, el compilador no entenderá el código que se ha escrito, y lanzará un error. Aprender a programar consiste en dominar una serie de conceptos (como el de las variables que se acaba de explicar), pero también en saber implementarlos o escribirlos en un programa para que se puedan transformar en un ejecutable. A continuación, aprenderéis la primera sintaxis de un programa C.

 

2. Definición de variables

Para definir una variable de un tipo de dato, es necesario seguir la sintaxis que se introduce a continuación. La definición depende del tipo de datos. Seguidamente, incluimos todas las opciones:

Pseudocódigo
	
C

var
    booleanVariable: boolean;
    integerVariable: integer;
    realVariable: real;
    charVariable: char;
end var 

	
#include <stdbool.h>

int main() {
    bool booleanVariable;
    int integerVariable;
    float realVariable;
    char charVariable;
}

Fijaos en un par de cosas:

El tipo de variable bool en C no es un tipo nativo, es decir, no está definido en C tal cual. Para poder utilizar las variables bool en C, tal y como os explicamos en este curso, debéis escribir la línea #include <stdbool.h>. Con esta línea añadimos nuevas funcionalidades en C. En este caso, añadimos la posibilidad de usar variables booleanas y les podemos asignar los valores true o false.
Los nombres de las variables deben ser únicos: no se puede llamar a dos variables con el mismo nombre, aunque sean de tipos diferentes. Por eso, los nombres que hemos elegido empiezan con el tipo de variable. No obstante, al crear una variable, el nombre puede ser el que queráis.

 

Recordad

Para usar una variable de tipo bool en C, debéis añadir la línea #include <stdbool.h> al principio del código.

 

Si pueden definir varias variables del mismo tipo de la siguiente manera:

Pseudocódigo
	
C

var
    booleanVariable1, booleanVariable2: boolean;
    integerVariable1, integerVariable2: integer;
    realVariable1, realVariable2: real;
    charVariable1, charVariable2: char;
end var 

	
#include <stdbool.h>

int main() {
    bool booleanVariable1, booleanVariable2;
    int integerVariable1, integerVariable2;
    float realVariable1, realVariable2;
    char charVariable1, charVariable2;
}

Hay una serie de normas que deben seguirse al elegir un nombre para una variable:

Los nombres pueden contener letras, dígitos y guiones bajos, pero no espacios en blanco ni caracteres especiales como !, #, ç, ñ, %, etc.
Los nombres deben empezar con una letra o un guión bajo (_)
Los nombres distinguen entre mayúsculas y minúsculas (myVar y myvar son variables distintas)
Las palabras reservadas (como int ) no se pueden utilizar como nombres.

Por convención, los nombres de las variables se escriben en minúscula. Si el nombre de la variable está formado por dos palabras, la primera letra del segundo término se escribe en mayúscula. Esto es lo que se llama camelCase

. 

En el pseudocódigo, aparecen una serie de palabras en negrita. Estas palabras forman parte de la sintaxis del pseudocódigo. En el código, en cambio, aparecen coloreadas. Estas palabras sirven para que el compilador (el intérprete del código escrito) entienda en cada momento qué se quiere hacer. Se llaman palabras clave (o reservadas) del lenguaje y no se pueden utilizar como nombre ni de variables ni de constantes. Cada lenguaje de programación tiene sus palabras clave, aunque la mayoría coinciden entre los diferentes lenguajes.

De ahora en adelante, siempre que se vean palabras en negrita en un algoritmo significará que son palabras clave del lenguaje algorítmico y se podrán distinguir del resto.

 

3. Asignación de variables

Anteriormente, hemos dicho que es aconsejable que, una vez definida una variable, se inicialice. Para hacerlo, hay que asignarle un valor. Asignamos un valor a una variable de la siguiente manera:

Pseudocódigo
	
C

var
    booleanVariable: boolean;
    integerVariable: integer;
    realVariable: real;
    charVariable: char;
end var 

booleanVariable := false;
integerVariable := 0;
realVariable := 0.0 ;
charVariable := 'a';

	
#include <stdbool.h>

int main() {
    bool booleanVariable;
    int integerVariable;
    float realVariable;
    char charVariable;

    booleanVariable = false;
    integerVariable = 0;
    realVariable = 0.0;
    charVariable = 'a';
}

En pseudocódigo, para asignar un valor a una variable se utiliza el operador de asignación :=, que se lee «toma por valor».

En C, se utiliza el operador = .

En este punto, os queremos hacer unas aclaraciones en relación con la asignación de valores a variables en C. En concreto, con variables de tipo bool. Fijaos en el ejemplo anterior: hemos definido la variable booleanVariable; luego, le hemos asignado el valor true, y, en la siguiente línea, le hemos asignado el valor false:

#include <stdbool.h>

int main() {
    bool booleanVariable;

    booleanVariable = true;
    booleanVariable = false;
}

 

¡Atención!

Las palabras true y false son reservadas en C y son los valores que puede tomar una variable bool. Al introducir las variables booleanas en 2. Tipos elementales de datos, explicamos que false se puede relacionar con 0 y true con 1. Pero no debemos equivocarnos al escribir el código en C: no debemos asignar los valores 0 o 1 a una variable bool, sino que tenemos que asignar solamente los valores true o false. Tampoco hace falta utilizar comillas antes y después de true o false. Eso también sería un error, que comprenderemos mejor cuando estudiemos las cadenas de caracteres.

 

4. Definición de constantes

A veces, en un programa se utilizan valores o parámetros que son relevantes para que funcione. Estos parámetros pueden ser números y, en general, puede que no resulte fácil identificarlos de un vistazo. Por ejemplo, es más fácil identificar el número 42 si decimos que es el número de plantas de un hotel (NUM_FLOORS) o 3.14159 si decimos que es el número π (pi).

Si para emplear estos parámetros en un programa utilizamos una constante en lugar de poner el número en cada fórmula, conseguiremos dos cosas:

El nombre de la constante nos dice qué número es el que estamos codificando y es más fácil de identificar en operaciones o fórmulas.
Si hay que cambiar el número de plantas de un hotel de 42 a 43, lo haremos en la definición de la constante, y quedará ya cambiado todas las veces que se usa en el programa (en lugar de ir a cada línea en la que consta 42 y cambiarlo por 43).

La definición de estas constantes se realiza de la siguiente manera:

Pseudocódigo
	
C

const
    PI: real = 3.1415926;
    MAX_STUDENTS: integer = 50;
    IVA: integer = 21;
    BLANK_CHAR:  char  = ' ';
end const

	
#define PI 3.1415926
#define MAX_STUDENTS 50
#define IVA 21
#define BLANK_CHAR ' '

 

5. Alcance y variables globales

Tal vez no os hayáis dado cuenta de un detalle muy importante: todas las variables que hemos definido en los programas C presentados en esta unidad estaban dentro del programa principal main. Esto se debe a una razón que hay que comentar, por mucho que quizá ahora sea difícil de entender.

En C, cuando una variable se define dentro de llaves, {}, el programa considera que esa variable solo se puede utilizar entre esas llaves. Así pues, cuando definimos una variable dentro del programa main, es decir, entre las llaves que definen este programa, la variable no puede utilizarse fuera de estas. Esto es lo que se llama alcance de una variable (en inglés, scope); es decir, las líneas de código dentro de una de estas llaves en las que se puede utilizar la variable que se ha definido. 

El alcance (scope) de una variable es el contexto en el que la variable es definida, es decir, las líneas de código en las que la definición de la variable es correcta o válida. En C, el alcance de una variable viene determinado por las llaves, {}, en las que está definida. 

Os pedimos que no lo hagáis, pero tenéis que saber que es posible definir variables fuera de la función main. Si os fijáis, fuera de la función main no hay llaves, {}, por lo que, si definimos una variable fuera de esta función, su alcance será todo el programa. Estas son las llamadas variables globales.

Las variables globales son aquellas que tienen un alcance que abarca todo el programa. Están definidas fuera de la función main (o cualquier otra función).

Es necesario evitar las variables globales.

Como os decíamos, aunque ahora no es fácil ver la razón, el uso de variables globales puede conllevar problemas: puede que desarrollemos una parte del código y definamos una variable que pensamos que no existe, pero que alguien haya creado una variable global con este nombre. Si bien parece que no sea un problema grave, lo cierto es que puede tener consecuencias indeseables, así que insistimos en que no lo hagáis y que defináis las variables solo dentro de la función main (u otra función que generéis, pero eso ya lo veremos en el futuro).

 

Resumen

 

Una variable es un nombre simbólico que hace referencia a una información concreta o a unos datos que se guardan en memoria. Al trabajar con variables, en vez de trabajar con un valor concreto, se escriben instrucciones que deberían funcionar para cualquier valor que tome esa variable.
Una variable consta de los siguientes atributos y características:
Nombre o identificador.
Tipo de dato que la codifica.
Valor.
Dirección de memoria.
Visibilidad. 
Para utilizar una variable, hay que definirla siguiendo la sintaxis adecuada e inicializarla con un valor.

Para inicializar una variable o para cambiar su valor en todo un programa, hay que poder asignarle valores, ya sea directamente o mediante una operación.

A veces, será necesario definir constantes, es decir, datos que no cambian a lo largo del programa. Es importante recordar que es una buena práctica definir constantes cuando se van a utilizar números (como pi u otros parámetros) en las operaciones de un programa. Así, será más fácil cambiarlos en todo el programa si fuese necesario.
El alcance (scope) de una variable es el contexto en el que la variable es definida.

Se deben evitar las variables globales, que son aquellas que tienen un alcance que engloba todo el programa.
